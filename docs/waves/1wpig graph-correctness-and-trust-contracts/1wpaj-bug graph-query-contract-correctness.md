## Rationale

`wf_graph_report` truncates ranked sections before applying external/generated filters. A `limit=1` project-only fan-in request therefore returns an empty list even though project nodes exist below the external top result, regressing the completed public requirement that filtering precede truncation. `code_callhierarchy` also projects away edge relation and confidence plus node kind and ID, so consumers cannot apply the documented trust policy to individual hierarchy entries.

## Requirements

1. Graph-report eligibility filters SHALL run before top-N truncation for every affected ranking section and supported collapse view.
   The required matrix for `fan_in`, `fan_out`, `chokepoints`, and `file_hubs` is all eight boolean combinations of the public `collapse_generated_files`, `collapse_class_module_pairs`, and `collapse_package_to_directory` flags, crossed with filter modes none, external-only, generated-only, and combined. For every applicable cell, the metamorphic oracle is the first requested `N` eligible rows from that exact collapsed topology's complete deterministic unfiltered candidate order. `betweenness` is supported only when all three collapse flags are false: any collapsed request that includes it SHALL return no stale base-topology ranking, set `betweenness_computed=false`, and expose `betweenness_skipped_reason="unsupported_for_collapsed_view"`; the uncollapsed cell is crossed with all four filter modes. `communities` remains an artifact-defined base-topology section: collapse flags do not project or rerank it, its complete base order SHALL be invariant across all eight flag combinations, and supported generated eligibility SHALL run before top-N; external filtering is not applicable because community members are project nodes. `orphan_docs` is an unranked diagnostic set and is outside the refill matrix.
   The matrix SHALL be countable and discriminating, not merely enumerated. The cell count is settled here rather than deferred: 176 cells. Four ranking sections crossed with eight collapse combinations and four filter modes is 128; uncollapsed betweenness crossed with four filter modes is 4; collapsed betweenness is the unsupported contract across the seven collapsed combinations crossed with four filter modes, which is 28; communities is eight collapse combinations for base-order invariance crossed with the two applicable generated-eligibility modes, which is 16. The filter modes are crossed in both of the cases the earlier range left open, because an unsupported contract that leaks a stale row under one filter mode and not another is exactly the defect the contract exists to prevent. Every counted cell SHALL be constructed so it CAN fail: the fixture SHALL place at least one ineligible candidate above the Nth eligible row in the unfiltered order, and each cell SHALL carry a deletion check proving it goes red when its own red-maker is reverted. The red-maker differs by family and SHALL be named per family rather than assumed to be one repair: for the 99 filtered refill cells (the four ranking sections and uncollapsed betweenness across the three modes that request a filter) it is filter-before-truncation; for the 33 unfiltered cells of those same sections it is unfiltered-order preservation, because with no filter requested neither filter branch executes and reordering is the only observable defect, so the mutant is a perturbed sort key compared against a RECORDED byte-for-byte unfiltered baseline; the baseline SHALL be a stored fixture captured on the repaired tree BEFORE the mutant is applied, and the check SHALL compare against those stored bytes rather than re-deriving them, because a baseline regenerated on the mutated tree restores the exact circularity this rule removes, and because the reference and the response come from the same sort expressions differing only in limit; for the 28 collapsed-betweenness cells it is the collapsed-unsupported guard, since reverting filter-before-truncation leaves them green; for the 8 generated-mode community cells it is eligibility-before-top-N; and for the 8 remaining community cells it is base-order invariance across collapse flags, which no eligibility filter reaches. A cell that cannot discriminate on the fixture available SHALL be marked not-applicable with a stated reason and SHALL NOT be counted as coverage. The escape has a floor, because otherwise coverage can legitimately collapse back to the single observation the live corpus supplies: every section crossed with every filter mode APPLICABLE to that section SHALL retain at least one counted cell, and not-applicable SHALL be justified by a property of the fixture rather than by its cost. The applicability exemption is narrow and is a property of the tool contract rather than of any fixture: the external-only and combined modes do not apply to `communities`, because external filtering never reaches that section, which is why its count is eight combinations across two modes rather than four. This discipline is required because the live corpus cannot supply it: measured on builder version 45, the eight collapse combinations yield two distinct topologies with identical top rows, no node carries the `generated` tag, and no module reaches the `file_hubs` threshold, so the whole cross reduces to two distinct observations and the pre-repair code passes nearly every cell.
   The reference order SHALL come from an internal call at a large limit, because the public tool clamps to `max(1, min(limit, 100))` and a capped public response cannot express the complete candidate order. The source differs by section and SHALL be named per section rather than assumed: `fan_in`, `fan_out`, `chokepoints`, and `file_hubs` come from `GraphQueryIndex.report`, which emits only those sections plus `orphan_docs`; that method truncates at THREE sites, the shared ranking helper serving the two fan sections plus a separate inline slice in each of chokepoints and file hubs, and it accepts no eligibility argument today, so the repair threads a predicate or the two flags into the method and edits all three sites, and editing the shared helper alone would fix only half the matrix; `betweenness` comes from the complete persisted order Requirement 6 introduces, not from `report`; and `communities` comes from `graph_cluster.read_cluster_payload(...)['communities']`, since both are assembled in `wf_graph_report_response` from the cluster payload and never pass through `report` at all. The test SHALL apply its OWN eligibility predicate to that order rather than reimplementing the ranking, or the oracle is circular.
   Two contract changes SHALL be declared rather than presented as ordering repairs. `exclude_generated` currently filters `fan_in`, `fan_out`, `chokepoints`, and `betweenness`, and separately drops generated-dominated communities, but does not reach `file_hubs`, while `exclude_external` does; the `file_hubs` generated-bearing cells are therefore a NEW filter that changes output for existing callers, and the tool description SHALL be updated to match. ## Scope

**In scope:** Report ranking/filter order, generated/external filters, complete persisted betweenness refill data, cluster artifact versioning, hierarchy response projection, MCP descriptions, public-handler regression tests, the bounded standing-evaluator identity/per-fixture/predecessor scaffold, and the unique run A/B/C graph-regression receipt chain.

## Risks

| Risk | Mitigation |
| --- | --- |
| Pre-filtering changes historical rank composition. | Preserve sort keys and compare unfiltered results byte-for-byte. |
| Added response fields increase payload size. | Fields are compact and limited to already-returned entries; measure the WORST-CASE response against the highest-degree symbol, per Requirement 3, not a representative one. |
| Complete betweenness order enlarges the cluster artifact. | Keep the compatibility top-N view, gzip the existing artifact as today, and gate compressed-size plus rebuild-time deltas on the current repository. |
| A caller expects betweenness to compose with collapse flags. | Return a stable, documented `unsupported_for_collapsed_view` reason and preserve all non-betweenness collapsed report sections. |
| The evaluator scaffold changes indexed source before baseline. | Land and index the bounded scaffold first, freeze its successor digest, then capture run A/B before any graph production edit. |
| Rebuild or evaluator retries make readiness evidence unbounded. | Enforce the per-sample and sequence timeouts, one rebuild attempt per sample, four evaluator invocations, explicit call/report-size ceilings, unique failed-attempt retention, and operator direction after exhaustion. |
| Caller paths or concurrent publication subvert an internally consistent receipt. | Use one sequence driver, fixed/direct-child regular paths, no symlinks/aliases, single-handle baseline hashing, atomic exclusive creation, start/end artifact digests, and fail-closed lock/token checks without a run-wide lock. |
