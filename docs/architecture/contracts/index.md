# Behavior contracts

Owner: Engineering
Status: active
Last verified: 2026-11-24

Behavior contracts describe what callers and operators can rely on across releases. A change spec describes the work for one delivery and its acceptance criteria. An architecture decision records why the project chose a design.

- [MCP tool surface (repository only)](https://github.com/coryhacking/wavefoundry/blob/main/docs/architecture/contracts/mcp-tool-surface.md) lists the tools, their inputs, and what callers should expect from each response.
