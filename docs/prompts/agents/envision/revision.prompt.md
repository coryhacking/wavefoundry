# Envision — Revision and preservation

Owner: Engineering
Status: active
Last verified: 2026-10-30

Internal phase guidance for revising an existing vision. Apply the core's authority and output boundaries.

Read the existing vision and its working references before editing. Identify the authorized revision, canonical location, adoption and explicit evidence-location policy. Preserve valid material and unrelated operator edits; reconcile contradictions rather than append a competing account. When reopening an early/provisional vision, retain worthwhile ambition as an explicit option unless rejected. Synthesize newly clarified uses and beneficiaries into the purpose and explain substantive directional changes without treating permission to revise as permission to shrink.

Incorporate needed conclusions from existing research/review siblings into the argument, preserving unique evidence and usable links. Existing siblings alone do not select the output policy or authorize their modification. Report historical siblings left unchanged and distinguish their older revision coverage from current coverage. Do not silently invalidate them by presenting old review as current. Retirement, relocation or deletion requires operator direction and preservation of unique evidence/references. If a requested consolidation cannot preserve a consequential reference, expose the conflict before that edit.

An explicit project/operator evidence-location instruction overrides the default; a single-document request rules out new companions. If substantial separately reusable research justifies an exception otherwise, state the concrete purpose before creating it. Review accounting remains in the response unless explicitly directed elsewhere. Read-only advice changes no artifact.
